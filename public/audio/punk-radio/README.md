# Audios de RADIO KLANDESTINA

Por derechos de autor, las canciones de Eskorbuto NO están incluidas en GitHub.

Para pruebas locales privadas, añade los MP3 como 01.mp3 hasta 09.mp3 en esta carpeta y respeta los permisos aplicables. Estos ficheros están excluidos por .gitignore.

El reproductor también permite seleccionar archivos de audio desde el dispositivo del usuario sin enviarlos al servidor.
