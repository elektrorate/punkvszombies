# PUNK GARDEN

Videojuego 2D de defensa por carriles con estética punk cartoon underground.

## Estado del repositorio

Proyecto en fase inicial. La documentación de diseño y los módulos de RADIO KLANDESTINA se irán incorporando progresivamente. El código del videojuego completo todavía está pendiente de desarrollo.

## Tecnología prevista

- Phaser 3
- TypeScript
- Vite
- Resolución lógica 1280 × 720

## Derechos musicales

No se incluyen canciones de Eskorbuto ni otros audios comerciales en este repositorio. Su uso y distribución requieren los permisos correspondientes.
